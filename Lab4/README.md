# Lab 4 - Додаток відстеження прогресу семестру

## Опис
Android-додаток для відстеження стану проходження навчання у семестрі. Користувач може переглядати список предметів, бачити всі лабораторні роботи для кожного предмета, змінювати їх статус та додавати коментарі. Всі дані зберігаються у локальній базі даних Room.

## Функціональність

### Екрани додатка:

1. **Екран списку предметів** (`SubjectsListScreen`)
   - Показує список з 5 предметів семестру
   - Кожен предмет відображається у вигляді Material3 Card
   - При натисканні на предмет відкривається екран деталей з лабораторними роботами

2. **Екран деталей предмета** (`SubjectDetailsScreen`)
   - Відображає назву предмета
   - Показує статистику: всього робіт, виконано, в процесі, відкладено
   - Список всіх лабораторних робіт з кольоровими індикаторами статусу
   - При натисканні на лабораторну роботу відкривається діалог редагування

3. **Діалог редагування лабораторної роботи** (`EditLabDialog`)
   - Вибір статусу з випадаючого списку (Не розпочато, В прогресі, Відкладено, Виконано)
   - Поле для додавання/редагування коментаря
   - Збереження змін у базу даних

## Предмети та лабораторні роботи:

1. **Мережева безпека** - 12 лабораторних робіт
2. **Розгортання інформаційно-комунікаційних систем** - 8 лабораторних робіт
3. **Економіка та підприємництво** - 1 лабораторна робота
4. **Проєктування мультисервісних систем** - 8 лабораторних робіт
5. **Програмування мобільних додатків** - 7 лабораторних робіт

**Всього: 36 лабораторних робіт**

## Статуси лабораторних робіт:

- ⚫ **Не розпочано** (NOT_STARTED) - Сірий колір
- ▶️ **В прогресі** (IN_PROGRESS) - Синій колір
- ⏰ **Відкладено** (POSTPONED) - Помаранчевий колір
- ✅ **Виконано** (COMPLETED) - Зелений колір

## База даних Room

### Таблиці:

**subjects** - Таблиця предметів
- `id` (INT, PRIMARY KEY) - Унікальний ідентифікатор
- `title` (TEXT) - Назва предмета

**subjectsLabs** - Таблиця лабораторних робіт
- `id` (INT, PRIMARY KEY) - Унікальний ідентифікатор
- `subject_id` (INT, FOREIGN KEY) - ID предмета (зв'язок з таблицею subjects)
- `title` (TEXT) - Назва лабораторної роботи
- `description` (TEXT) - Опис лабораторної роботи
- `comment` (TEXT) - Коментар користувача
- `status` (TEXT) - Статус виконання (NOT_STARTED, IN_PROGRESS, POSTPONED, COMPLETED)

### Зв'язки:
- Один предмет може мати багато лабораторних робіт (One-to-Many)
- При видаленні предмета видаляються всі його лабораторні роботи (CASCADE DELETE)

## Як працює додаток

1. При запуску додатка відкривається екран зі списком предметів
2. Дані завантажуються з Room Database через DAO інтерфейси
3. При першому запуску база даних ініціалізується з попередньо завантаженими даними
4. Користувач може натиснути на предмет, щоб побачити його лабораторні роботи
5. На екрані деталей відображається статистика та список робіт з індикаторами статусу
6. Натиснувши на лабораторну роботу, користувач може:
   - Змінити статус через випадаючий список
   - Додати або редагувати коментар
   - Зберегти зміни у базі даних
7. Після збереження список автоматично оновлюється з новими даними

## Особливості реалізації

- **Асинхронність** - Всі операції з базою даних виконуються в окремих корутинах (не блокують UI)
- **LaunchedEffect** - Використовується для завантаження даних при створенні екрана
- **State Management** - Використання `remember` та `mutableStateOf` для управління станом UI
- **Material3 Components** - Card, AlertDialog, ExposedDropdownMenuBox, OutlinedTextField
- **Type Safety** - Використання Navigation3 з типобезпечними аргументами
- **Database Migration** - Підтримка fallbackToDestructiveMigration для спрощення розробки
- **Enum для статусів** - Типобезпечне представлення статусів лабораторних робіт
- **Foreign Keys** - Підтримка цілісності даних через зовнішні ключі
