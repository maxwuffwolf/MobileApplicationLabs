# Lab 3 - Додаток туристичних місць України

## Опис
Простий Android-додаток, який показує популярні туристичні напрямки в Україні. Користувач може переміщатися між різними екранами, щоб переглянути деталі вибраного місця.

## Функціональність

### Екрани додатка:

1. **Екран списку місць призначення** (`PlacesListScreen`)
   - Показує список популярних туристичних місць України
   - Кожне місце відображається у вигляді картки (Material3 Card) з назвою та коротким описом
   - При натисканні на картку відбувається перехід на екран деталей

2. **Екран деталей пункту призначення** (`PlaceDetailsScreen`)
   - Відображає повну інформацію про вибране місце
   - Показує назву, повний опис та додаткову інформацію
   - Використовує Material3 компоненти для красивого відображення

## Туристичні місця в додатку:

1. **Київ - Софійський собор** - Пам'ятка XI століття, внесена до списку ЮНЕСКО
2. **Львів - Старе місто** - Історичний центр з середньовічною архітектурою
3. **Карпати - Говерла** - Найвища вершина України (2061 м)
4. **Одеса - Потьомкінські сходи** - Символ міста на Чорноморському узбережжі
5. **Чернівці - Резиденція митрополитів** - Архітектурний комплекс XIX століття
6. **Кам'янець-Подільський - Фортеця** - Середньовічна фортеця на скелястому острові
7. **Хортиця - Національний заповідник** - Історичний центр українського козацтва
8. **Умань - Софіївка** - Дендрологічний парк XVIII століття

## Технології

- **Kotlin** - мова програмування
- **Jetpack Compose** - сучасний UI toolkit для Android
- **Material3** - дизайн-система Material Design 3
- **Navigation3** - бібліотека для навігації між екранами
- **Kotlinx Serialization** - для роботи з даними

## Структура проекту

```
app/src/main/java/com/lab3/
├── data/
│   └── ItemsData.kt              # Дані про туристичні місця
├── ui/
│   ├── navigation/
│   │   └── NavigationGraph.kt    # Налаштування навігації
│   ├── screens/
│   │   ├── placesList/
│   │   │   └── PlacesListScreen.kt    # Екран списку місць
│   │   └── placeDetails/
│   │       └── PlaceDetailsScreen.kt  # Екран деталей місця
│   └── theme/                    # Налаштування теми додатка
└── MainActivity.kt               # Головна активність
```

## Як працює навігація

1. При запуску додатка відкривається `PlacesListScreen`
2. Користувач бачить список туристичних місць
3. При натисканні на місце викликається `onDetailsScreen(id)`
4. Додаток переходить на `PlaceDetailsScreen` з відповідним ID
5. На екрані деталей показується повна інформація про вибране місце

## Особливості реалізації

- **Singleton pattern** для `ItemsData` - дані доступні з будь-якого місця додатка
- **State Management** - використання `remember` та `mutableStateOf` для управління станом
- **Material3 Components** - Card, Text з різними стилями для привабливого UI
- **Typography** - використання типографічної системи Material3
- **Adaptive Layout** - підтримка різних розмірів екранів
